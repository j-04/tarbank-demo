# AI usage

I formulated and own the requirements, design, and implementation plan. Several AI models were used as review partners to identify possible gaps, inconsistencies, and edge cases in those documents.

Most implementation code was produced with AI assistance under my supervision. I directed the work, reviewed the output, and made the final technical decisions. A separate AI agent was also used to review the code for defects, gaps, and risks.

AI was used to accelerate drafting, implementation, and review; it did not replace engineering judgment or accountability for the final project.
